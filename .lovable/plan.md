

## Быстрый переход к записи по дате в разделе "Энергия дней"

### Что будет сделано
В секции "Энергия дней" добавится поле выбора даты (date picker). При выборе даты:
- Если запись на эту дату уже существует -- она автоматически открывается на редактирование (как если бы вы нажали карандаш)
- Если записи нет -- форма заполняется с этой датой для создания новой записи

Это избавит от необходимости скроллить список в поисках нужной записи.

### Технические детали

**Файл: `src/components/admin/ContentManagement.tsx`**

1. Добавить новое состояние `searchDate` (строка типа `string`)
2. Добавить поле ввода даты рядом с заголовком карточки "Энергия дней" с кнопкой "Найти"
3. При выборе даты и нажатии кнопки (или onChange):
   - Ищем в `dailyEnergyList` запись с совпадающей датой
   - Если найдена -- вызываем `handleEditDailyEnergy(energy)` для этой записи и раскрываем список (`setShowAllEnergy(true)`)
   - Если не найдена -- загружаем запись напрямую из БД запросом `SELECT * FROM life_navigator.daily_energy WHERE date = '...'`
   - Если и в БД нет -- заполняем форму новой записи с выбранной датой
4. Поле поиска даты будет простым `<Input type="date">` с кнопкой перехода, размещённым в заголовке карточки
